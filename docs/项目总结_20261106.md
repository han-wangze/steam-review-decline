## 二、方案设计

### 2.1 为什么是这个岗位、这个问题

岗位定在 DA/BA 而不是算法岗，因为三条硬约束：没有深度学习栈、没有大厂算法实习、无论文。而畅游战略分析实习提供的"发行侧决策语言"是稀缺项，应该放大。

问题选"会不会掉档"而不是"好不好"，因为发行商在第 30 天要做的决定是**继续投钱还是止损**，不是给游戏打分。

### 2.2 口径（全部集中在 `config.py`）

```
t0        = 首条评论时间（与发行日中位偏差 0 天）
特征窗口   = [t0, t0+30d]
标签窗口   = [t0+30d, t0+365d]        ← 与特征窗零重叠
快照       = 2023-11-02，只保留窗口完整的游戏
```

### 2.3 架构（L0–L5，单向依赖）

```
L0 数据   HF 分片 222 个（步长 3）
L1 聚合   aggregate.py  → 一次扫描算出 7/30/90/180/365 天 + 全量 + 累计曲线
L2 标签   label.py      → 三种口径 + 筛选漏斗 + 新旧对照
L3 特征   features.py   → 12 个特征，物理限制在 30 天内
L4 建模   train.py      → 时间切分 / 消融 / 校准 / 回归 / 漂移校正
L5 导出   export.py     → JSON + 归因 + 先验校正
          site/index.html → 单页，无后端、无 CDN、file:// 可开
```

三条结构性保障：口径常量只有一个来源；特征函数拿不到窗口外数据；`check.py` 把纪律写成断言。

### 2.4 为什么不用更复杂的模型

训练集只有 130 个正例。这个量级上，LightGBM / 神经网络 / 文本嵌入都是在拟合噪声——之前实测过：24 个文本主题特征塞进 201 个样本，AUC 从 0.868 掉到 0.766。**特征数量必须服从样本量**，这句话我能拿数据证明。

## 三、已完成的工作

### 3.1 数据层（可复现）

| 工作 | 结果 |
|---|---|
| 分片聚合重写 | 一次扫描出全部窗口；与旧版在 2,830 款游戏上**逐条完全一致** |
| 跨分片脏数据 | 识别出 appid 730（评论被切到多个 part），样本中排除 |
| 筛选漏斗 | 35,487 → 2,526，每一步剔除量与原因都有记录 |

### 3.2 标签层

| 工作 | 结果 |
|---|---|
| 固定观察窗口 | 所有样本观察期恒为 365 天（旧版 366–4,765 天浮动） |
| 窗口不重叠 | 标签改用第 30–365 天，消除"早期评论占标签一部分"的机制性相关 |
| 三种口径并列 | 旧 / 中 / 新同时保留，可直接对比 |
| 窗口敏感性 | 90 天 63 正例 / 180 天 125 / 365 天 207（未筛选前） |

### 3.3 建模与验证

| 工作 | 结果 |
|---|---|
| 时间切分 | ≤2018 训练（1,128 / 130 正例），2019–2022 测试（1,398 / 85 正例） |
| 消融 | 5 组，去掉最强特征后仍有 0.674 |
| 校准 | 发现并修掉 `class_weight` 污染，ECE 0.253 → 0.050 |
| 连续目标 | Ridge 预测好评率变化，Spearman 0.309 |
| 漂移诊断 | 排除"测量噪声"与"结构变化"，确认为真实行为变化（断点） |
| 漂移校正 | 先验校正，ECE 0.050 → 0.022，年内排序严格不变 |
| 时间加权 | 测试后否定（AUC 0.886 → 0.884/0.885） |
| **滚动切分（7 折）** | **AUC 中位 0.861，范围 0.846–0.911，极差 0.066 → 0.886 可信** |
| **门槛敏感性（30/50/100）** | **AUC 0.883 / 0.886 / 0.898，极差 0.015 → 结论不敏感** |
| **决策曲线** | **p_t ≤ 25% 时优于"全部复核"；最优操作点 p_t = 8–10%** |

## 四、关键数字总表

### 4.1 标签口径如何改变结论（最重要）

| 标签口径 | 单特征 AUC | 全模型 AUC | 模型增量 |
|---|---|---|---|
| 旧：全量评论（观察期浮动） | 0.900 | 0.901 | +0.001 |
| 中：365 天累计（含重叠） | 0.926 | 0.929 | +0.003 |
| 新：只看 30–365 天（不重叠） | 0.872 | 0.886 | +0.014 |

### 4.2 主结果

| 模型 | AUC | 95% CI | AP | P@10% | lift | ECE |
|---|---|---|---|---|---|---|
| 常数基线 | 0.500 | — | 0.061 | 6.1% | 1.0 | 0.054 |
| 单特征好评率 | 0.872 | — | 0.327 | 28.8% | 4.7 | — |
| 全特征 LogReg | 0.886 | [0.86, 0.91] | 0.343 | 30.2% | 5.0 | 0.050 → 0.022 |
| 全特征 RF | 0.866 | [0.83, 0.90] | 0.319 | 30.9% | 5.1 | 0.046 |

### 4.3 消融

| 特征组 | AUC | AP |
|---|---|---|
| A 仅好评率 | 0.872 | 0.327 |
| B 好评率 + 评论量 | 0.884 | 0.295 |
| C 去掉好评率 | 0.674 | 0.112 |
| D 去掉评论量 | 0.885 | 0.346 |
| E 全特征 | 0.886 | 0.343 |

### 4.4 评论量的作用是有条件的

| 早期好评率 | 10–100 条 | 100–400 条 | 400+ 条 |

### 4.6 稳健性（新增）

| 检验 | 结果 | 判定 |
|---|---|---|
| 滚动切分 7 折（2015→2016 … 2021→2022） | AUC 中位 **0.861**，范围 0.846–0.911，极差 0.066 | 通过（<0.08）：0.886 可信，但中心是 0.861 |
| 门槛敏感性 n_late ∈ {30, 50, 100} | AUC 0.883 / 0.886 / 0.898，极差 0.015 | 通过（<0.05）：结论不敏感 |
| 决策曲线 | p_t ≤ 25% 时优于"全部复核"；最优 p_t = 8–10% | 可用：复核 22% 抓 68/85 |

### 4.7 决策曲线关键点

| 决策阈值 | 复核比例 | 命中率 | 抓到降档 | 每百款净增 |
|---|---|---|---|---|
| 5% | 33.0% | 16.3% | 75/85 | +2.77 |
| **10%** | **21.9%** | **22.2%** | **68/85** | **+2.97** |
| 20% | 13.0% | 28.6% | 52/85 | +1.39 |
| 30% | 8.1% | 31.0% | 35/85 | +0.11 |
| 40% | 5.4% | 31.6% | 24/85 | −0.76 |

一句话：**只要一次漏报的代价大于约 3 次误报，用模型就比全查更划算。**
